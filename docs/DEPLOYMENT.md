# Deployment Guide

## Overview

This guide covers deploying Klinisk AI Assistent to Vercel and other platforms.

## Prerequisites

- Flutter 3.24 or later installed
- Git installed and configured
- Vercel account (free tier works)
- GitHub account

## Vercel Deployment (Recommended)

### Method 1: Vercel Dashboard (Easiest)

1. **Push to GitHub**
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/[username]/klinisk-ai-assistent.git
git push -u origin main
```

2. **Import to Vercel**
- Go to https://vercel.com/new
- Click "Import Git Repository"
- Select your GitHub repository
- Configure build settings:
  - **Framework Preset**: Other
  - **Build Command**: `flutter build web --release --web-renderer canvaskit`
  - **Output Directory**: `build/web`
  - **Install Command**: `flutter pub get`

3. **Deploy**
- Click "Deploy"
- Wait 2-5 minutes for build
- Your app is live!

### Method 2: Vercel CLI

1. **Install Vercel CLI**
```bash
npm install -g vercel
```

2. **Login**
```bash
vercel login
```

3. **Deploy**
```bash
# First deployment
vercel

# Production deployment
vercel --prod
```

4. **Configure vercel.json** (already included)
```json
{
  "version": 2,
  "buildCommand": "flutter build web --release --web-renderer canvaskit",
  "outputDirectory": "build/web",
  "framework": null,
  "installCommand": "flutter pub get"
}
```

### Method 3: GitHub Actions (Automatic)

The included `.github/workflows/deploy.yml` automatically deploys on push to main.

**Setup:**
1. Get Vercel token: https://vercel.com/account/tokens
2. Add GitHub secrets:
   - `VERCEL_TOKEN`
   - `VERCEL_ORG_ID` (from vercel.com/account)
   - `VERCEL_PROJECT_ID` (from project settings)

3. Push to main branch:
```bash
git push origin main
```

**Workflow automatically:**
- Installs Flutter
- Runs tests
- Builds web app
- Deploys to Vercel

## Custom Domain Setup

### Vercel Custom Domain

1. Go to project settings in Vercel
2. Navigate to "Domains"
3. Add your domain (e.g., `klinisk.ai`)
4. Update DNS records:
   - **A Record**: Point to Vercel IP
   - **CNAME**: Point to `cname.vercel-dns.com`

5. Wait for DNS propagation (5-60 minutes)
6. HTTPS automatically configured

### Domain Examples
- `klinisk.ai` - Main domain
- `app.klinisk.ai` - Subdomain
- `klinisk-ai.vercel.app` - Default Vercel domain

## Alternative Hosting Platforms

### Netlify

1. **netlify.toml**
```toml
[build]
  command = "flutter build web --release"
  publish = "build/web"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

2. **Deploy**
```bash
netlify deploy --prod
```

### Firebase Hosting

1. **Install Firebase CLI**
```bash
npm install -g firebase-tools
```

2. **Initialize**
```bash
firebase init hosting
# Select build/web as public directory
```

3. **Deploy**
```bash

```

### GitHub Pages

## Troubleshooting Deployment

### Build Fails

**Issue**: Flutter not found
```bash
# Solution: Specify Flutter version in GitHub Actions
- uses: subosito/flutter-action@v2
  with:
    flutter-version: '3.24.0'
```

**Issue**: Dependencies not installed
```bash
# Solution: Run pub get before build
flutter pub get
flutter build web
```

### Runtime Errors

**Issue**: API calls blocked by CORS
- Should not happen (direct API calls)
- Check API endpoint URLs
- Verify HTTPS

**Issue**: Service Worker not updating
```bash
# Clear cache
- Hard reload (Ctrl+Shift+R)
- Clear Application Cache in DevTools
```

### Performance Issues

**Issue**: Slow initial load
- Use CanvasKit renderer
- Enable compression
- Check network throttling

**Issue**: Large bundle size
```bash
# Analyze bundle
flutter build web --analyze-size

# Tree shake icons
flutter build web --tree-shake-icons
```
